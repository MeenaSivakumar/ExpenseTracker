# Income & Expense Tracker

A simple React + TypeScript project that allows users to:

- Add income and expense entries
- Edit existing records
- Delete records
- View all statements in a table format

## Features

✅ Add statement with:
- Description
- Category (Income or Expense)
- Amount

✅ Display statements in a table:
- Incomes shown with `+` sign in green
- Expenses shown with `-` sign in red

✅ Edit a specific statement:
- Opens the form with default values of the selected row
- Updates the row after submission

✅ Delete a specific statement

✅ Final total is displayed at the end:
  - Total = Total Income - Total Expense
